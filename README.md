# SU-03T 本地离线配置工具

用于 Windows 10/11 64 位的便携工具，可在本地配置唤醒词、命令词、模块串口引脚和识别后发送的数据，并生成可烧录固件。

## 下载和使用

1. 到 [Releases](https://github.com/HAOTIANGUO22/SU03T/releases) 下载 **SU03T.zip**。
2. 完整解压，打开 `SU03T_Offline_Portable` 文件夹。
3. 双击 **启动工具.cmd**，在浏览器打开的本地页面配置和生成固件。
4. 点击“打开烧录工具”，如 Windows 弹出管理员权限确认，请手动确认，再选择生成的固件。
5. 下载完成后，关闭烧录工具，断电重启模块并实机验证。

无需安装 Python，也无需登录智能公元。接入硬件烧录时，电脑可能需要对应的 USB 转串口驱动。

请下载 Release 中的 **SU03T.zip**；GitHub 自动提供的 Source code ZIP 仅包含仓库说明，不是完整工具。

## 当前功能与范围

- 可配置中文唤醒词、命令词；支持范围以本地发音映射、冲突和语法容量检查结果为准，并非任意中文均保证支持。
- 可选择模块串口引脚、串口参数以及 HEX/文本等发送内容；默认 TX B0 / RX B1，9600、8N1。
- 保存配置并本地生成固件；识别后回复语音目前保留“收到”。
- 便携运行环境、编译工具和烧录工具随发行包提供，保留各组件原有声明。

这是工程验证版本。默认 B0/B1 串口发送及“小智小智”唤醒词已进行实机验证；新配置仍需实测。当前“智能洗衣机”示例已通过本地生成和文件校验，实机验证尚未完成。
